# Désactiver la mémoire

Comment empêcher ChatGPT, Claude et Gemini de mémoriser vos conversations. Les encadrés et les flèches rouges sur les captures indiquent où cliquer. Les interrupteurs sur les captures sont déjà désactivés — c'est l'état attendu une fois terminé.

> ⚠️ Faites-le **avant de commencer les tâches**, pour **les trois** modèles.

## ChatGPT

1. Ouvrez ChatGPT et connectez-vous.
2. Cliquez sur votre icône de profil ou votre nom (en bas à gauche), puis sur **Settings**.
3. Cliquez sur **Personalization** dans la barre latérale gauche.
4. Désactivez **Enable memory**.
5. Sur les anciennes versions, désactivez **Reference saved memories** et **Reference chat history**.

![ChatGPT — Personalization, mémoire désactivée](media/memory-guide/image4.png)

**Application mobile :** menu ou photo de profil → **Settings** → **Personalization** → désactivez **Memory**.

## Claude

1. Ouvrez Claude et connectez-vous.
2. Cliquez sur votre nom (en bas à gauche), puis sur **Settings**.
3. Ouvrez **Your Claude** (appelé **Memory** ou **Capabilities** selon les versions).
4. Sous **Memory**, désactivez **Generate memory from chats** et **Search and reference chats**.
5. Si vous voyez **Pause memory**, choisissez-la — elle empêche Claude d'utiliser ou de créer des souvenirs, tout en conservant ceux déjà enregistrés.

![Claude — Settings, options de mémoire](media/memory-guide/image1.png)

![Claude — mémoire désactivée](media/memory-guide/image3.png)

## Gemini

1. Allez sur Gemini et connectez-vous.
2. Cliquez sur l'icône des paramètres (en bas à gauche) ou sur le **Menu (☰)** en haut à gauche, puis sur **Settings**.
3. Cliquez sur **Personal Intelligence** (ou **Memory**).
4. Désactivez **Memory**.

![Gemini — Personal Intelligence, mémoire désactivée](media/memory-guide/image5.png)

![Gemini — mémoire désactivée](media/memory-guide/image2.png)

**Application mobile :** **Menu (☰)** → votre photo de profil → **Personal Intelligence** (ou **Memory**) → désactivez **Memory**.
