# メモリをオフにする

ChatGPT、Claude、Gemini にチャットを記憶させないようにする方法です。スクリーンショットの赤い枠と矢印が、クリックする場所を示しています。スクリーンショットのトグルはすでにオフになっており、完了時はこの状態になります。

> ⚠️ **タスク開始前に**、**3 つすべて**のモデルで行ってください。

## ChatGPT

1. ChatGPT を開いてサインインします。
2. 左下のプロフィールアイコンまたは名前をクリックし、**Settings** を選びます。
3. 左側のサイドバーで **Personalization** をクリックします。
4. **Enable memory** をオフにします。
5. 古いバージョンでは、**Reference saved memories** と **Reference chat history** をオフにします。

![ChatGPT — Personalization、メモリをオフにした状態](media/memory-guide/image4.png)

**モバイルアプリ:** メニューまたはプロフィール写真 → **Settings** → **Personalization** → **Memory** をオフにします。

## Claude

1. Claude を開いてサインインします。
2. 左下の名前をクリックし、**Settings** を選びます。
3. **Your Claude**（バージョンによっては **Memory** または **Capabilities**）を開きます。
4. **Memory** の下で、**Generate memory from chats** と **Search and reference chats** をオフにします。
5. **Pause memory** が表示されたら選択します。Claude がメモリを使ったり作成したりするのを止め、保存済みのものは保持します。

![Claude — Settings、メモリのオプション](media/memory-guide/image1.png)

![Claude — メモリをオフにした状態](media/memory-guide/image3.png)

## Gemini

1. Gemini にアクセスしてサインインします。
2. 左下の設定アイコン、または左上の **Menu (☰)** をクリックし、**Settings** を選びます。
3. **Personal Intelligence**（または **Memory**）をクリックします。
4. **Memory** をオフにします。

![Gemini — Personal Intelligence、メモリをオフにした状態](media/memory-guide/image5.png)

![Gemini — メモリをオフにした状態](media/memory-guide/image2.png)

**モバイルアプリ:** **Menu (☰)** → プロフィール写真 → **Personal Intelligence**（または **Memory**）→ **Memory** をオフにします。
