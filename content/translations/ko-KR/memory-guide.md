# 메모리 끄기

ChatGPT, Claude, Gemini가 대화를 기억하지 못하게 하는 방법입니다. 스크린샷의 빨간 상자와 화살표가 클릭할 위치를 보여 줍니다. 스크린샷의 토글은 이미 꺼져 있으며, 완료되면 이 상태여야 합니다.

> ⚠️ **작업 시작 전에**, **세 가지 모두**의 모델에서 수행하세요.

## ChatGPT

1. ChatGPT를 열고 로그인합니다.
2. 왼쪽 하단의 프로필 아이콘이나 이름을 클릭한 다음 **Settings**를 클릭합니다.
3. 왼쪽 사이드바에서 **Personalization**을 클릭합니다.
4. **Enable memory**를 끕니다.
5. 이전 버전에서는 **Reference saved memories**와 **Reference chat history**를 끕니다.

![ChatGPT — Personalization, 메모리 꺼짐](media/memory-guide/image4.png)

**모바일 앱:** 메뉴 또는 프로필 사진 → **Settings** → **Personalization** → **Memory** 끄기.

## Claude

1. Claude를 열고 로그인합니다.
2. 왼쪽 하단의 이름을 클릭한 다음 **Settings**를 클릭합니다.
3. **Your Claude**(버전에 따라 **Memory** 또는 **Capabilities**)를 엽니다.
4. **Memory** 아래에서 **Generate memory from chats**와 **Search and reference chats**를 끕니다.
5. **Pause memory**가 보이면 선택하세요 — Claude가 메모리를 사용하거나 생성하지 못하게 하고, 저장된 것은 유지합니다.

![Claude — Settings, 메모리 옵션](media/memory-guide/image1.png)

![Claude — 메모리 꺼짐](media/memory-guide/image3.png)

## Gemini

1. Gemini에 접속하고 로그인합니다.
2. 왼쪽 하단의 설정 아이콘이나 왼쪽 상단의 **Menu (☰)**를 클릭한 다음 **Settings**를 클릭합니다.
3. **Personal Intelligence**(또는 **Memory**)를 클릭합니다.
4. **Memory**를 끕니다.

![Gemini — Personal Intelligence, 메모리 꺼짐](media/memory-guide/image5.png)

![Gemini — 메모리 꺼짐](media/memory-guide/image2.png)

**모바일 앱:** **Menu (☰)** → 프로필 사진 → **Personal Intelligence**(또는 **Memory**) → **Memory** 끄기.
