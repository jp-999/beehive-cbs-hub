# Turn off memory

How to stop ChatGPT, Claude and Gemini from remembering your chats. The red boxes and arrows in the screenshots show what to click. The toggles in the screenshots are already off — that is how they should look when you are done.

> ⚠️ Do this **before tasking**, for **all three** models.

## ChatGPT

1. Open ChatGPT and sign in.
2. Click your profile icon or name (bottom-left), then **Settings**.
3. Click **Personalization** in the left sidebar.
4. Turn off **Enable memory**.
5. On older versions, turn off **Reference saved memories** and **Reference chat history**.

![ChatGPT — Personalization, memory turned off](media/memory-guide/image4.png)

**Mobile app:** menu or profile picture → **Settings** → **Personalization** → turn off **Memory**.

## Claude

1. Open Claude and sign in.
2. Click your name (bottom-left), then **Settings**.
3. Open **Your Claude** (called **Memory** or **Capabilities** in some versions).
4. Under **Memory**, turn off **Generate memory from chats** and **Search and reference chats**.
5. If you see **Pause memory**, choose it — it stops Claude from using or making memories and keeps the saved ones.

![Claude — Settings, memory options](media/memory-guide/image1.png)

![Claude — Memory turned off](media/memory-guide/image3.png)

## Gemini

1. Go to Gemini and sign in.
2. Click the settings icon (bottom-left) or the **Menu (☰)** at the top left, then **Settings**.
3. Click **Personal Intelligence** (or **Memory**).
4. Turn off **Memory**.

![Gemini — Personal Intelligence, memory turned off](media/memory-guide/image5.png)

![Gemini — Memory turned off](media/memory-guide/image2.png)

**Mobile app:** **Menu (☰)** → your profile picture → **Personal Intelligence** (or **Memory**) → turn **Memory** off.
